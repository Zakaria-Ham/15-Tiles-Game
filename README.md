A modern, highly interactive implementation of the classic 15-puzzle sliding game built with **React** and **TypeScript**. 

Beyond standard gameplay, this project features an advanced **built-in AI solver** using the Iterative Deepening A* (IDA*) search algorithm, capable of calculating optimal move paths, providing real-time hints, and auto-solving the board.

🔗 **Live Demo:** [https://15-tiles-game.vercel.app](https://15-tiles-game.vercel.app)

---

## 🛠️ Tech Stack & Tools

* **Framework:** React (using Functional Components & Hooks)
* **Language:** TypeScript for strict typing and scalable code architecture.
* **Styling:** Pure CSS (Modular component-based stylesheets).
* **State Management:** React `useState` and `useEffect` for complex board states, timer synchronization, and solution paths.
* **Algorithms:** Implementation of IDA* Search with Manhattan Distance and Linear Conflict heuristics.
* **Web APIs:** Native `navigator.share` and Clipboard API for seamless score sharing.

---

## ✨ Key Functionalities

### 1. Core Gameplay Mechanics
* **Guaranteed Solvability:** The board is generated by shuffling a solved state backward with valid moves, ensuring every generated puzzle can be solved.
* **Fluid Interactions:** Click-to-slide mechanics automatically detect adjacent empty spaces and validate legal moves.
* **Dynamic Highlighting:** The UI provides visual feedback for hints and solution paths using state-driven CSS styling.

### 2. Advanced AI Solver (The "Smart" Features)
The game includes a highly optimized solver built directly into the client-side logic:
* **Real-time Hints (💡):** Calculates the optimal path to victory from the current state and highlights the exact next tile the user should move.
* **Full Solution Engine (🧩):** Generates the complete sequence of moves required to solve the puzzle from any state.
* **Algorithmic Depth:** Utilizes **IDA* (Iterative Deepening A*)** alongside two powerful heuristics to ensure high performance without freezing the browser:
  * **Manhattan Distance:** Calculates the baseline grid distance of every tile from its target position.
  * **Linear Conflict:** Adds penalties for tiles that are in their correct row/column but inverted with another tile, drastically reducing the search space.

### 3. Game State & Time Management
* **Precision Timer:** Tracks the exact time taken to solve the puzzle.
* **Pause/Resume:** Allows players to pause the timer (freezing the board to prevent cheating).
* **Game Controls:** Options to instantly Restart the exact same puzzle or generate a completely New Game.

### 4. Smart Sharing System
* **Victory Screen:** Detects a winning state immediately and displays a victory overlay.
* **Cross-Platform Sharing:** Uses the modern Web Share API (`navigator.share`) on supported mobile devices to share scores directly to native apps (WhatsApp, Twitter, etc.).
* **Clipboard Fallback:** Automatically falls back to copying the formatted score to the user's clipboard on desktop browsers.
